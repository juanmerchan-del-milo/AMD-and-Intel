# PC Lab Builder 3D para Android

Contenedor Android sin conexión para el constructor 3D, el catálogo completo y el laboratorio AMD/Intel.

## Compatibilidad e instalación

- Android 7.0 o posterior (API 24+).
- El APK de publicación conserva el identificador y la clave de las versiones anteriores, por lo que puede actualizar una instalación compatible sin desinstalarla.
- Si Android bloquea la instalación, habilita temporalmente **Instalar apps desconocidas** para el navegador o gestor de archivos desde el que abriste el APK.
- Si aparece un conflicto de firma al actualizar una copia obtenida de otra fuente, desinstala únicamente esa copia y vuelve a instalar el APK oficial de GitHub Releases.

GitHub Actions genera y verifica `PC-Lab-Builder-3D-1.24.0-Android.apk`.
