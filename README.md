# AMD Intel CPU Lab v1.22.0

Aplicación interactiva para explorar, comparar y entender procesadores AMD e Intel, con vistas 3D, generaciones, portátiles, mini PCs, gráficos integrados, NPU/IA y especificaciones.

## Descargas

- **Android:** APK instalable desde GitHub Releases.
- **iPhone / iPad:** abre la PWA en Safari → Compartir → **Añadir a pantalla de inicio**.
- **Windows:** instalador EXE y versión portable.
- **Linux:** AppImage y tar.gz.
- **macOS:** DMG y ZIP para Intel x64 y Apple Silicon arm64.
- **Web:** PWA preparada para GitHub Pages con caché offline.

**Releases:** https://github.com/juanmerchan-del-milo/AMD-and-Intel/releases/latest

**Web / PWA:** https://juanmerchan-del-milo.github.io/AMD-and-Intel/

## Apple

La PWA funciona en iPhone/iPad sin App Store. Una IPA nativa instalable directamente en un iPhone real requiere firma con Apple Developer, certificado y perfil de aprovisionamiento. Los paquetes de macOS se generan sin notarización comercial, por lo que macOS puede mostrar una advertencia la primera vez.
