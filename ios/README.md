# PC Lab Builder 3D para iPhone / iPad

La versión instalable sin cuenta Apple Developer es la PWA:

1. Abre https://juanmerchan-del-milo.github.io/AMD-and-Intel/ en Safari.
2. Toca **Compartir**.
3. Elige **Añadir a pantalla de inicio**.
4. Se abrirá como una aplicación independiente y quedará disponible sin conexión después de completar la primera carga.

La PWA incluye el constructor, catálogo y laboratorio. Una IPA nativa para instalar directamente en un iPhone real requiere firma Apple Developer, certificado y perfil de aprovisionamiento; por eso no se distribuye una IPA sin firmar que iOS rechazaría.
